# Eval seeds (not shipped)

This directory is intentionally **empty** in the public competition release.

Official evaluation uses a **hidden** seed list generated by the organizers with a private `--rng-seed` salt. See [COMPETITION.md](../COMPETITION.md) and [eval/README.md](../README.md).

For local development, generate your own seeds:

```bash
python -m eval.select_eval_seeds \
  --config eval/configs/grasp_part.yaml \
  --n-seeds 5 --rng-seed 42 \
  --out /tmp/grasp_part_dev.json
```

Do **not** commit generated seed files to git.
